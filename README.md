# NIFTY 50 Stock Market Analysis

## 📊 Project Overview

This project analyzes NIFTY 50 stock market data from 2020 to 2025 using Python, SQL and Power BI.

The objective is to identify market trends, daily returns, price movements and volatility and present the findings through data analysis and an interactive dashboard.

---

## 🎯 Business Problem

Analyze NIFTY 50 historical market data to understand:

- Stock price trends over time
- Year-wise average closing prices
- Daily market returns
- Market volatility
- Major market declines
- Moving average trends
- Overall market performance

---

## 🛠️ Tools & Technologies

- **Python** – Data cleaning, transformation and analysis
- **Pandas** – Data manipulation
- **Matplotlib** – Data visualization
- **PostgreSQL** – Data storage and SQL analysis
- **Power BI** – Interactive dashboard and visualization
- **GitHub** – Project documentation and portfolio
