## 📌 Project Overview

This project is an end-to-end **NIFTY 50 Stock Market Analysis** project developed using **Python, PostgreSQL/SQL and Power BI**.

The project analyzes historical NIFTY 50 market data from **2020 to 2025** to understand market trends, price movements, daily returns, moving averages, volatility and year-wise performance.

The project follows a complete Data Analytics workflow:

**Raw Data → Data Cleaning → Python Analysis → PostgreSQL → SQL Analysis → Power BI → Business Insights**

The final outcome is an interactive Power BI dashboard supported by Python-based analysis and SQL queries.

---

# 🎯 Business Problem

Financial market data contains large volumes of daily trading information, making it difficult to identify important trends and market movements directly from raw data.

The objective of this project is to analyze historical NIFTY 50 data and answer important analytical questions such as:

- How has NIFTY 50 performed from 2020 to 2025?
- How has the closing price changed over time?
- Which years had higher average closing prices?
- What were the major daily market declines?
- When did market volatility increase significantly?
- How does the 20-day moving average explain market trends?
- What patterns can be observed in daily returns?
- How did the market behave during periods of major disruption?

---

# 🎯 Project Objectives

The major objectives of this project are:

1. Collect historical NIFTY 50 market data.
2. Combine multiple yearly datasets into one dataset.
3. Clean and prepare the data using Python.
4. Perform feature engineering and calculate financial metrics.
5. Store the cleaned data in PostgreSQL.
6. Perform analytical SQL queries.
7. Analyze market trends using Python visualizations.
8. Build an interactive Power BI dashboard.
9. Identify important market trends and volatility periods.
10. Present the complete project as a GitHub Data Analytics portfolio project.

# 📂 Dataset Description

The project uses historical **NIFTY 50 market data covering 2020–2025**.

### Dataset Period

**01 January 2020 – 31 December 2025**

### Total Records

**1,492 records**

### Dataset Coverage

The project combines six yearly historical CSV files:

- NIFTY 50 – 2020
- NIFTY 50 – 2021
- NIFTY 50 – 2022
- NIFTY 50 – 2023
- NIFTY 50 – 2024
- NIFTY 50 – 2025

---

# 📋 Original Dataset Columns

The original datasets contain the following fields:

| Column | Description |
|---|---|
| Index Name | Name of the market index |
| Date | Trading date |
| Open | Opening value of NIFTY 50 |
| High | Highest value during the trading day |
| Low | Lowest value during the trading day |
| Close | Closing value of NIFTY 50 |
